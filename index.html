El método — Proof of work
Sin seguimiento longitudinal: transporte óptimo
El mismo algoritmo que usa Amazon para rutas de entrega — el algoritmo de Sinkhorn — aplicado a distribuciones por franja etaria, con una sola restricción: el DVP no retrocede.

El problema

  • Solo teníamos datos de corte transversal
  • Sin pares de observaciones, no hay transición directa
  • Los grados son ordinales y monotónicos

La solución

  • Pares de franjas consecutivas: 55–59 → 60–64, etc.
  • Sinkhorn halla la matriz P que transforma A → B
  • Restricción: Pij = 0 si j < i (no regresión)
  • Validado por pseudocohorte — error L1 < 0.01
